KDP Submission Playbook

Claude Code for Everyone Else — everything you need to publish the eBook and paperback yourself, in order.

You do the clicking; this page has every value to paste and every file to upload. Publish the eBook first, then add the paperback as a linked format. Budget ~30–45 minutes.

0. Before you start one-time

  1. Sign in at kdp.amazon.com.
  2. If this is your first title, finish account setup: the tax interview and bank details. Nothing can be created until that is done.

Description (paste; bold the first line, italicize the title)
You do not need to be a programmer to build software anymore.

Claude Code is an AI agent that writes and runs code for you, right on your own computer. You describe what you want in plain English, and it builds it: a website, a small tool, a script that automates the boring parts of your week. This book takes you from never having opened a terminal to building and running your own projects.

Written for complete beginners. No coding background, no jargon, nothing assumed. Every step is shown with real screenshots, in plain language, at a pace that does not rush you.

Inside, you will:
- Open the terminal for the first time and stop being scared of it
- Install Claude Code and have your first real conversation with it
- Build a personal website from a single sentence
- Understand what Claude shows you, and when to say yes or no
- Fix things when they go wrong, and teach Claude about your project
- Save what works so you can do it again

By the end you will have built real things, and you will know how to keep going on your own.

If you have ever watched developers conjure things out of thin air and wished you could do that too, start here.

2. Add the Paperback

From the same title, choose Create Paperback (links it to the eBook). Details copy over; verify them.

Open the Print Previewer and check title/spine alignment and that the screenshots read clearly in grayscale. The cover spine is built for exactly 141 pages; if the interior page count ever changes, the cover must be rebuilt.

Pricing

Printing cost (US, 6×9 B&W white, 141 pp): $1.00 + 141 × $0.012 = $2.69. Minimum list for 60% royalty is about $4.49.

3. After publishing

  • Claim your author page at authorcentral.amazon.com; upload your photo and the bio below.
  • Verify the live listing: “Look Inside,” categories, the Buy button.
