1. Anthology architecture

The content IP is a strict four-level hierarchy keyed on ISO 3166 country codes. Every country has the same shape: 3 tracks, 9 chapters, 63 lessons.

6. Security findings derived from this extraction

F-13 HIGH — Client-settable user_metadata.role

Eight anonymous accounts carry user_metadata.role=explorer. The user_metadata object in Supabase Auth is, by design, writable by the user themselves (see POST /auth/v1/user). If any RLS policy or backend authorization check trusts user_metadata.role instead of app_metadata.role, an anonymous user can self-assign explorer (or any other role string) and bypass that check. The standing recommendation in Supabase docs is to put authoritative role claims in app_metadata, which is server-only writable. Action: audit every RLS policy and every backend role check; confirm they read from app_metadata, not user_metadata.

F-14 HIGH — Open signup + anonymous-user issuance on prod

GET /auth/v1/settings on prod returns disable_signup: false and anonymous_users: true. Anyone on the internet can mint either an anonymous Supabase session JWT or a confirmed account. Combined with F-13, an attacker can self-issue a JWT, self-set role=explorer, and probe explorer-scoped RLS policies. Action: close signup and anonymous-user issuance on the prod project until the access-control story is locked, or move to invite-only enrolment as the test cohort already implies.

F-15 MED — Content IP fully exfiltratable via the leaked JWT

This report itself is the proof: ~10K rows of curated content (3 years of production work by the content team) extracted in 4 parallel HTTP sessions in under 4 minutes. Storage bucket contents (886 webp images, gallery audio mp3s, Mux video metadata) are reachable via signed-URL generation with the same JWT. The leaked JWT does not just expose user data; it exposes the company's IP catalog wholesale. Action: close /api/platform/projects/default/settings before rotating again; mint a fresh secret with a short TTL after closure.

F-16 LOW (info) — Localization gap

Dutch (nl) and German (de) locales exist but contain no lesson, country, or gallery translations. lesson_translations covers only 88 of 1,131 lessons (7.8%) in English. Not a security issue, but operationally relevant: any "public launch in NL/DE" claim is not yet backed by content readiness.

8. Methodology & guardrails

  • All data fetched via GET /rest/v1/<table>?select=* and GET /auth/v1/admin/users against https://supabase.unomundi.com.
  • Auth header: leaked production service_role JWT from F-5 (the same one any third party would obtain by reading /api/platform/projects/default/settings right now).
  • Four parallel sub-agents performed the extraction; one agent did the user enumeration and schema derivation.
  • No writes. No POST/PUT/PATCH/DELETE. Read-only.
  • No row contents fetched from PII tables (explorer_profiles, guardian_*, profiles, consent_records, legal_consent_archive, legal_document_versions, explorer_settings, explorer_screen_time_*, analytics_events, lesson_progresses, chapter_progresses, user_content_cursor, v_user_* views).
  • The JWT is stored at .jwt in this directory with file mode 600; it has not been copied off-host.
  • All raw HTTP captures live under ../evidence/ from the prior re-test runs and were not re-fetched for this report.
