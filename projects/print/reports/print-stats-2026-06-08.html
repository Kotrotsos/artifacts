Match pipeline

Query → match stages

1 · normalize
resize+pad to 512×512 white canvas
2 · gray + CLAHE
contrast-equalized grayscale
3 · binary
adaptive threshold + morphology
4 · edges
Canny (50, 150)
5 · skeleton
1-pixel medial axis
6 · distance
Euclidean distance transform, viridis
7 · ORB
1000 keypoints, 8 scale levels
8 · descriptor
HOG on gray + HOG on edges + 4×4 edge density + Hu moments → 16,223-d, L2 normalized
9 · stage A
vectorized cosine vs. all rows → top 300
10 · stage B
ORB + Lowe ratio + RANSAC homography on top 300
11 · score
0.4 · descriptor + 0.6 · ORB_inliers/30
No deep learning. torch + transformers + torchvision pretrained loading all SIGSEGV on this Mac (numpy 2.4.4 / torch 2.9.1 ABI mismatch), so the match stack is pure OpenCV + scikit-image. Classical CV actually does well on partial prints because HOG and ORB target structure rather than global appearance.

Volume survives redeploys, so iterating on code (paste-to-upload, overlay aligner, etc.) doesn't re-trigger the 434 MB data shipment. Cloudflare's railway up upload cap (~300 MB) is the reason the data path is chunked HTTP rather than baked into the image.

UI features (current)

  • Upload, click test print, or Cmd/Ctrl-V paste from clipboard
  • Side-by-side query↔match grid (original / gray / binary / edges) per top-K result
  • ORB correspondence visualization with RANSAC inlier line drawing
  • Interactive overlay aligner: drag, scroll-to-scale, opacity / rotate / scale sliders, invert
  • Click-to-zoom lightbox on every image
  • Confidence pills (highmediumlow) calibrated from the combined score
  • Light / Dark / System theme toggle, light-mode default
  • Database browser at /db with descriptor sparkline per sole

Build journey

  • May 9Zalando scraper kicked off (curl_cffi + hydration JSON). 22,504 shoes scraped across men-streetwear / women / kids.
  • May 10Sole detection over 8 parallel workers using gpt-4o-mini vision. Hit insufficient_quota at ~1,000 soles; cleanup script removed confirmed-no-sole folders.
  • May 111,041 confirmed sole crops on disk. Visual spot-check gallery generated.
  • May 12Match MVP built. Pipeline + descriptor + ORB. FastAPI server on :8001 with match / database / overlay aligner UI.
  • Jun 7Railway deployment. Volume created at /app/data, 1,040-sole tarball uploaded via chunked HTTP after Cloudflare blocked the bundled image. Public URL live.
  • Jun 8Paste-to-upload added. This stats page generated.
