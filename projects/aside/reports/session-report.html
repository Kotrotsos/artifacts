Aside, recent session report

branch clean-slate, commits ff488cf to c1ff50d

00Summary

Across these sessions Aside was rebuilt around the "live call assistant" concept, with a transcript column on the right and a chat panel on the left where a passive AI companion can drop in observations, answer typed questions, and produce structured tickets. The underlying STT pipeline also gained a local Private mode via a WhisperKit sidecar, with a model download UI and a health check.

ASSISTANT

Passive chat companion

Greets after a few utterances, ticks every 15 seconds, follows standing instructions from the user, answers typed questions, and now emits structured ticket cards when the conversation produces a scoped feature or fix.

PRIVATE STT

Local WhisperKit, opt-in

Model large-v3_turbo at ~1.5 GB, runs on the Apple Neural Engine. Audio never leaves the machine. Heath probe + download progress wired into Settings.

RESILIENCE

System audio auto-reconnect

ScreenCaptureKit gets killed by macOS for legitimate reasons (display reconfig, recording indicator clicked). The helper now respawns up to three times with backoff, with toast events surfaced to the UI.

FOUNDATIONS

Clean slate first

The branch started by stripping back to audio capture, streaming transcription, and a single sentiment placeholder, deleting the previous cards, flags, tips, key quotes, ambient mode, mode selectors, and prompt config.

03Architecture, current shape

Event flow

mic (cpal)            sys (SCK helper)
   |                       |
   v                       v
audio::levels (VU, mute gate)
   |                       |
   v                       v
stt engine: Deepgram WS  OR  whisper sidecar over pipe
   |                       |
   '------ "transcript" ---'
                |
                v
       analysis::store (rolling 200)
        |               |
        v               v
processor loop      assistant loop (15 s)
 (no-op stub)       |          |
                    v          v
               chat msg     ticket
                    |          |
                    '----------'
                          |
                  "assistant-message"
                          |
                          v
                     frontend chat

Notable invariants

  • Mic is authoritative for echo dedup, system audio is never used to retroactively edit mic.
  • Mute is a runtime kill at audio::levels, the capture stream keeps producing samples, so unmute is instant.
  • Sequential ticket IDs are assigned server side as T-001, T-002, so the LLM never has to invent IDs.
  • Tickets and chat ride one event channel, the frontend discriminates by the optional ticket field on each message.
  • The processor loop is a placeholder, the assistant loop is the only consumer of the transcript store today.

05Outstanding

  • Assistant feels too chatty at exactly the 15 s cadence on talky calls, may need a small dampener for back to back ticks where nothing new has been added since the last assistant message.
  • Tickets list lives only in the chat scroll, no separate "captured tickets" pane, copy out, or export.
  • Private mode helper takes ~4 s warmup on first start, ~5 s for the model load before that, no UI signal during this period beyond log lines.
  • Local LLM path for Pass 2 of the local models spec is still unbuilt, the assistant still calls Anthropic when Private STT is active.
  • Mic side bleed into system audio in a real call with speakers will incorrectly suppress legitimate remote speech, the current asymmetric direction assumes mic is always primary.
