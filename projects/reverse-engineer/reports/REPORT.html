Claude.app v1.7196.0

Static reverse-engineering report. Compared against v1.5354.0 (~2 weeks prior). Analyzed 2026-05-15.

Headline: Operon (Anthropic's cloud workspace system) has been completely removed from the desktop IPC surface — 22 interfaces gone, both @anthropic-ai/operon-core and @anthropic-ai/operon-web dropped from package.json. The desktop is consolidating around Local Agent Mode + Cowork + Buddy, with cloud workspace state now living entirely server-side. The IPC channel count fell from 770 to 636 (–17%) in one release.

The five biggest changes

1. Operon teardown REMOVED

All 22 Operon* IPC interfaces removed: OperonAgents, OperonAnnotations, OperonApiKeys, OperonArtifactDownloads, OperonArtifacts, OperonAttachments, OperonBootstrap, OperonCloud, OperonConversations, OperonEvents, OperonExportBundle, OperonFolders, OperonFrames, OperonHostAccess, OperonMcp, OperonNotes, OperonPreferences, OperonProjects, OperonSecrets, OperonSkills, OperonSystem, OperonAnalytics. Both operon-core and operon-web packages are dropped from package.json. Cloud workspace work is now entirely server-side.

2. GrandPrix pairing surface NEW

New IPC interface claude.web_$_GrandPrix with pair(partnerId: string), disconnect(), and a Zustand-style grandPrixStatus_$store$_* triplet. The partnerId argument and origin-validated claude.web namespace look like a desktop-to-peer pairing flow (probably mobile companion or multi-device handoff), not a hardware device. No BLE transport accompanies it. See BUDDY.md for hypotheses.

3. Unified Interactive Auth replaces Vertex + Gateway SSO CHANGED

LocalAgentModeSessions now has triggerInteractiveAuth, revokeInteractiveAuth, and an interactiveAuth_$store$_* store. The old provider-specific triggerVertexAuth, revokeVertexAuth, vertexAuth_$store$_*, Custom3pSetup::gatewaySsoUserCode, and triggerGatewaySso are gone. One OAuth/interactive flow now covers Vertex, MCP, and any future SSO provider.

4. Custom MCP credential helpers NEW

New interface Custom3pHelperRun with runCredentialHelper and getCredentialHelperLastRun. Plus four new Custom3pSetup methods: authorizeAndProbeMcpServer, probeMcpServer, forgetMcpOAuth, openDeviceCodeWindowForE2e. Third-party MCP setup now feels like configuring a git remote — probe the endpoint, run a credential helper, persist via OAuth. Direction of travel: plug-and-play enterprise MCP.

5. Cowork artifact sharing live NEW

CoworkArtifacts gains shareArtifact, unshareArtifact, isSharingEnabled, refreshImportedArtifact. The old exportArtifact is removed. Artifacts can be shared between users now and pulled in fresh when the shared source changes — a live link rather than a one-shot export.

New IPC interfaces

Custom3pHelperRun NEW

Custom credential helpers for 3rd-party MCP servers, analog to git's credential helpers. 2 methods.

GrandPrix NEW

Peer pairing by partnerId string. 5 methods. Most likely a desktop-to-mobile companion pairing channel.

Buddy continues to mature

Buddy IPC is byte-identical to v1.5354.0: 14 methods on the Buddy interface, 4 on BuddyBleTransport, 2 on BuddyRemoteFeed. New in v1.7196: Buddy now has its own renderer window (buddy_window/) and a dedicated 59 KB preload (buddy.js). The install + pickFolder + preview + progress cluster confirms the device receives content from the desktop — not just a remote control, but something that displays or executes payloads pushed over BLE.

BLE library: noble. Custom service UUID unchanged from v1.5354 (still 584ef9d9-…4cec). Nordic UART Service UUIDs retained.

What didn't change

  • LAM (Local Agent Mode) microVM at ~/Library/Application Support/Claude/vm_bundles/claudevm.bundle/ — same layout, same gVisor netstack, same Apple Virtualization / Hyper-V split.
  • Framebuffer / VNC tool surface (13 framebuffer_* tools, 11 FramebufferPreview IPC methods).
  • iOS Simulator integration (5 methods).
  • CoworkMemory (7 methods, account + global memory).
  • Office "Pivot" Excel add-in (12 OfficeAddinFiles methods, manifest at pivot.claude.ai/manifest.xml).
  • Chrome extension + native messaging bridge.
  • Production model identifiers: claude-opus-4-6, claude-sonnet-4-6, claude-sonnet-4-5-20250929, claude-haiku-4-5-20251001. No new SKU yet.

Interpretation

Two themes:

  1. Desktop scope narrowing. Operon's removal plus the releaseWorktree / exportArtifact drops say the desktop is consolidating around local agent sessions, Cowork, Buddy, and the web view. Cloud workspace management is no longer the desktop's job.
  2. OAuth flow generalisation. One triggerInteractiveAuth replaces Vertex- and Gateway-specific code paths, and MCP setup gains probe + credential-helper machinery. This is enterprise-MCP plumbing maturing — the kind of work that makes a 3rd-party MCP integration feel like configuring a git remote.

The largest unknown is GrandPrix. Its partnerId-based pairing, web-origin caller, and total absence of BLE transport suggest a peer pairing channel — a v2 of the existing mobile bridge, a multi-account desktop pairing, or a hook for an upcoming Anthropic mobile/companion app.
