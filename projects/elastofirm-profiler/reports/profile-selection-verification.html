What changed

Selection moved from a checkbox click to direct card interaction, like a file manager. Plain click replaces the selection; Cmd/Ctrl toggles; Shift extends the range; double-click opens the profile; right-click opens a context menu scoped to the selection. Checkboxes are kept as a hover-reveal affordance. Built on the shadcn context-menu primitive, reusing the existing handlers (selectRange, toggleProfileComparison, categorizeSelected, handleExportComparisonToExcel, downloadDxf, setAnchor). Applies to both grid and list views.

How to verify it is OK

  1. Run a search so profile cards appear (grid or list view).
  2. Click a card once: it gets a green outline and a checkbox appears (single select).
  3. Cmd/Ctrl-click a second card: both stay selected. Shift-click a third: the whole range selects.
  4. Right-click any selected card: the menu shows only bulk actions (Categoriseren / Exporteer / Download DXF) with the count.
  5. Right-click a card that is NOT selected: selection jumps to just that card and the menu adds Open profiel / Gebruik als anker / Bekijk afbeelding.
  6. Double-click a card: the profile detail dialog opens.
  7. Click empty space between cards: the selection clears.
