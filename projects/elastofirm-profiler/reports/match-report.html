Each card takes one full profile, rotates it (the left tile, the query), then asks both matchers to find it back in the 6000-profile catalogue. Current (whole-image HOG) tends to lose it once rotated; Proposed (canon_dt: orientation-canonicalized + distance- transform HOG) straightens the shape first and recovers it. Each strip is ranked AND labelled by the same score, so order always matches the number.
