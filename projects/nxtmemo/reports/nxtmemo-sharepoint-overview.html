One stdio MCP server, one UI tool (browse_sharepoint). Claude Desktop iframes the card HTML; clicks inside the card re-call the tool with new params (path / query / fileId), which re-renders the card in place.

Setup

  1. Register an Entra ID app in the nxtphase10 tenant. Single-tenant. Under Authentication, set Allow public client flows to Yes (needed for device-code).
  2. Add delegated Microsoft Graph permissions: Files.Read.All, Sites.Read.All, User.Read, offline_access.
  3. cp .env.example .env, paste in AZURE_TENANT_ID and AZURE_CLIENT_ID.
  4. npm install && npm run signin. Open the printed URL, paste the code, sign in once.
  5. Add the server entry to ~/Library/Application Support/Claude/claude_desktop_config.json and fully quit Claude Desktop before reopening.

Tool surface

ParameterTypeBehaviour
pathstring?Folder path relative to the site drive root. Default: Zittingslijsten.
querystring?Full-text search; path scopes the search to that subtree.
fileIdstring?Drive item ID. Returns extracted text in the preview pane.

In normal use you only ever ask Claude to "open the SharePoint browser" once. The card itself drives all further navigation.

How interaction works

Every click inside the card posts a tool message to the host with toolName: "browse_sharepoint" and new params. The host invokes the tool, which returns fresh structuredContent; the iframe rerenders against it.

// click a folder
{ path: "/General/Operations/Projects/ANP/Zittingslijsten/2026" }

// type in search box, press Enter
{ query: "Amsterdam meervoudig", path: "/General/.../Zittingslijsten" }

// click a file row
{ fileId: "01ABCDEF234567890", path: "/General/.../Zittingslijsten" }

// click "Close" on preview / "Clear" on search
{ path: "/General/.../Zittingslijsten" }

Claude Desktop config snippet

{
  "mcpServers": {
    "nxtmemo-sharepoint": {
      "command": "/Users/marcokotrotsos/NXTPHASE/nxtmemo/node_modules/.bin/tsx",
      "args": ["/Users/marcokotrotsos/NXTPHASE/nxtmemo/src/server.ts"]
    }
  }
}

The absolute path to local tsx matters; Claude Desktop spawns without your shell's PATH.

Trigger phrase. Once the server is wired up, just ask Claude something like "Open the SharePoint browser" or "Show me this week's Zittingslijst". The first call renders the card; everything after that is clicks inside the card.
