WCAG 2.1 / 2.2 AA — Overview

Wat de accessibility branch heeft opgeleverd

Een rondgang door de a11y-features die op feature/accessibility_ in de agent-frontend zijn vastgelegd. Alleen wat aantoonbaar in code zit — geen openstaande punten.

Branch feature/accessibility_ WCAG 2.1 / 2.2 AA agent-frontend Nederlands

00Architectuurkeuze

Componenten met a11y-toevoegingen zijn verplaatst uit components/assistant-ui/thread.tsx naar components/civai/. De assistant-ui upgrade-CLI gebruikt aui-* comment-markers als anchors en herschrijft alles daarbinnen — alles in civai/ blijft intact bij upgrades.

  • civai/assistant-message.tsx — assistant message + action bar + StarIcon
  • civai/user-message.tsx — user message + edit action bar
  • civai/composer.tsx — composer, send/cancel, scroll-to-bottom, suggesties
  • civai/edit-composer.tsx — edit mode
  • civai/branch-picker.tsx — versie-navigatie

thread.tsx is teruggebracht van 489 naar 102 regels en bevat alleen nog de orchestrator, ThreadWelcome en de role="log" wrapper rond Messages.

05Wat dit oplevert

Toetsenbordgebruikers

Tab door composer, send, suggesties, message-acties en branch-picker. Skip-link springt naar hoofdinhoud.

Screen readers

Rol-aanduiding per bericht ("Assistent: ", "U: "), nieuwe tokens via aria-live, bronnen kondigen "opent in nieuw tabblad" aan.

Lage-zicht gebruikers

Duidelijke focus-ring op composer en alle buttons; contrast getest in light en dark mode.

Future-proof

A11y-attributen leven buiten de assistant-ui codegen-zone en blijven bij upgrades intact.
