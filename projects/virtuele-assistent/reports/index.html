Two independent prompt layers. A system prompt is assembled once per request from a tenant template plus database variables. Strategy prompts are short instructions injected at specific nodes of the agent graph as the request moves through routing, retrieval and answering.

Assembly modes

Request lifecycle, in one breath

  1. PII guard — PiiRedactionService.redact() masks IBAN, e-mail, phone, passport, licence and BSN before anything leaves the backend.
  2. Classify — nodeClassify (GPT-4.1 Mini, temp 0, org prompt stripped) routes to PROCEED, DISAMBIGUATE or REDIRECT.
  3. Route — disambiguate or redirect answer directly; PROCEED enters the tool loop.
  4. Retrieve — tools run the RAG pipeline: HyDE, vector + keyword search, RRF fusion, rerank.
  5. Answer — answer_prompt (round 1) or answer_forced_prompt (round 2+) synthesizes the sourced reply.
  6. Stream + trace — response streams out; Langfuse records the trace and automatic scores.
