agentlog
How it works

One place for everything your agents make.

agentlog stores, organises and shares the artifacts your agents create, the HTML reports, examples and Markdown docs, addressed by project, tag, title and version. Push from a Chrome extension or a skill, view it in a clean web app, share it with a click.

The big picture

Three ways in, one organised store

An agent produces an artifact. You capture it from the browser or straight from the agent. agentlog versions it, files it under the right project and tag, and gives you a link to share.

The address of every artifact

project / tag / title / version

Every artifact lives at a predictable path. The project is the top-level space (asked for first if it is new). The tag is a category like requirements or design ideas. The title is the document. The version is assigned automatically.

Never overwrite anything

Versions are historical by default

Upload the same project, tag and title again and agentlog simply adds the next version. The newest is served as the latest, older ones are kept as history. No version numbers to manage, nothing lost.

Getting artifacts in

Capture from anywhere

Chrome extension

On any artifact page, click the icon, set project, tag and title, and save the page. It grabs the full HTML for you.

The skill

Tell your agent to store an artifact and the skill uploads the file directly, asking which project it belongs to first.

REST API

A single authenticated POST from a script or your own tooling. Same endpoint the extension and skill use.

What happens on upload

From click to link

curl -X POST https://agentlog-production.up.railway.app/api/upload \
  -H "Authorization: Bearer agl_…" \
  -H "Content-Type: application/json" \
  -d '{"project":"Acme Site","tag":"reports",
       "title":"Launch Report","content":"<h1>Hi</h1>",
       "content_type":"text/html"}'
Sharing

Access that cascades down

Grant a person access at any level and they get everything beneath it. Give someone the whole project and they see every tag and document inside. Grant a single tag and they see only that category. Grant one document and that is all they get. Or flip on a public link for view-only access with no account.

Safe by design

Rendering untrusted HTML, safely

Sandboxed artifacts

Saved HTML is served under a strict content-security-policy sandbox, in an isolated origin. Interactive reports still run, but a stored artifact can never reach your session, cookies or the surrounding page.

Scoped tokens and grants

API tokens are hashed at rest and only act for their owner. Web sessions are signed, http-only cookies. Every document view is checked against the cascading grant rules before a byte is served.

Get going

Quickstart

  1. Create an account at agentlog and sign in.
  2. Generate an API token under API tokens. Copy it once, it is shown only at creation.
  3. Connect a source. Paste the URL and token into the Chrome extension settings, or export AGENTLOG_URL and AGENTLOG_TOKEN for the skill.
  4. Push an artifact. Set project, tag and title, then save. agentlog versions it and returns a link.
  5. Share it. Grant a teammate at the project, tag or document level, or enable a public link.
