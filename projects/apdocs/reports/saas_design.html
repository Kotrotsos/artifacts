APDOCS — SaaS design proposal

An audit-first SaaS for managing Back-to-Birth document packages. The lifecycle timeline is the spine of the product; every feature attaches to it. Every fact carries provenance and a determinism profile, so a regulator or buyer can verify any claim in two clicks.

01 Design pillars

1

Timeline-first

Every screen anchors to the engine's lifecycle. Documents, components, and open items all hang off the timeline as the primary axis.

2

Audit-by-default

Every value shown carries provenance — file, page, region, extraction method. Two clicks from any Trace Pack claim to its source PDF crop.

3

Determinism contract visible

Facts are tagged DET, HYB, NON. Reviewer can filter "show me all non-deterministic facts in this package" and verify them in one pass.

4

Multi-actor by design

Internal engineers, external suppliers, buyers, regulators — each gets the right view. Supplier portal is a first-class product, not an afterthought.

11 Deployment

Single-tenant per customer (APOC gets their own Azure tenant). The SaaS layer is the multi-tenant control plane; data and compute live in the tenant. Lines up with APOC's Workstream 1 (private Claude deployment).

Customer tenant (APOC's Azure)

  • Blob storage — source packages, OCR sidecars, Trace Packs
  • Postgres or Cosmos — the index from schema sketch
  • Azure AI Search — Smart Search index
  • Document Intelligence (fallback OCR)
  • Claude on Foundry (private endpoint)
  • Entra ID — auth, SSO, RBAC
  • App Service — UI + portal
  • Functions — pipeline workers

Multi-tenant control plane (NxtPhase)

  • Validation rule definitions (versioned)
  • Doc-type catalogue (versioned)
  • Skill: APDOCS (this skill)
  • SaaS UI image, redeployable per tenant
  • Determinism contract enforcement library
  • Monitoring & metrics (anonymous)
  • Customer onboarding tooling

APOC's data never leaves their tenant. NxtPhase ships rule and UI updates as versioned releases. Each release is reviewable as a diff — what new flags will be raised, what new fields will be extracted.

12 The pitch in one paragraph

APDOCS is a timeline-first SaaS for aviation Back-to-Birth document review. Every engine package becomes a navigable lifecycle. Every fact carries a determinism tag — deterministic rule, hybrid OCR, or AI judgement — so any claim in a delivered Trace Pack is verifiable in two clicks. The system runs in the customer's Azure tenant alongside their private Claude deployment; nothing leaves. Documentation engineers review and approve; suppliers correct via expiring portal links; buyers receive a signed PDF with a full provenance appendix. The first measurable outcome: reduce a typical 40-80 hour manual review to under 6 hours of decision-only human time, while making the result more defensible than the current manual process.
