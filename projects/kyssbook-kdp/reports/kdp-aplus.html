MODULE 5

The full pitch

Standard Product Description Text

No image. Up to 6,000 characters. The first line is bolded to act as a header (this module has no built-in header style).

If you build on Claude, this is the reference that reads like a book.

Most platform docs are built to be searched, not read. This book takes the entire Claude developer platform and turns it into something you can read cover to cover, or open to the one chapter you need. You go from a single call to the Messages API all the way to running managed agents in sandboxes, governing usage and cost across an organization, and wiring up tools, skills, and MCP. Streaming, prompt caching, structured outputs, batch processing, rate limits, compliance, keyless authentication, cloud deployment: it is all here, in order, each piece building on the one before it. Every code example is shown the way you see it on your own machine. Every chapter opens by explaining what a thing is and why it exists before showing you how to use it. Whether you are shipping your first feature on Claude or standardizing how a whole team builds on it, this is the field guide to keep next to your editor.

How to add it in KDP

01KDP Bookshelf → the book's "..." menu → Edit A+ Content (or Marketing → A+ Content Manager). Pick the English / Amazon.com marketplace.
02Add the five modules in order: Image & Text Overlay, Three Images and Text, Single Left Image, Single Image & Sidebar, Product Description Text.
03Upload each image, then paste the copy from the blocks above into the matching field.
04For Module 1, put the text in the overlay box, not on the image. For Module 5, the first line is bold to act as the header.
05Preview (it sits below the fold under "From the Publisher"), then Submit for approval. Review usually takes up to 72 hours.
